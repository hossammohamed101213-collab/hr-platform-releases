# مواصفات تنفيذ «مركز القيادة المركزي» (SEVEN Command Center)
> تُسلَّم هذه المواصفات للشات/المطوّر الذي يعمل على مشروع «المخ» (Node.js على Coolify). الهدف: تطبيق ويب واحد يراه المالك قدّامه، فيه مجسّمات ثلاثية الأبعاد للسيرفرات والمنصات والبرنامج، يضغط على أي عنصر يطلع بياناته، ويسأل بالكتابة أو بالصوت ويرد عليه بالنص والصوت. **كل شيء مجاني بلا اشتراكات**: لا ذكاء اصطناعي مدفوع، لا خدمات صوت مدفوعة.

---

## 1) القواعد الحاكمة
1. **قراءة فقط** من كل المصادر. مركز القيادة لا يعدّل ولا يحذف أي بيانات في أي نظام.
2. **مجاني 100%**: المكتبات من CDN (three.js)، الصوت عبر Web Speech API في المتصفح (التعرّف والنطق)، فهم الأسئلة بقواعد وكلمات مفتاحية (بدون API مدفوع). لو أُضيف ذكاء اصطناعي لاحقاً يكون اختيارياً ومعطّلاً افتراضياً.
3. **الأسرار** في متغيرات بيئة Coolify فقط. لا تُكتب في الكود ولا على GitHub.
4. **الدخول** للمركز بكلمة مرور واحدة (متغير `CC_PASSWORD`) + جلسة كوكي؛ الصفحة لا تفتح بدونها.
5. **العربية المصرية** في الواجهة والردود. الاسم الظاهر: **مركز القيادة المركزي — SEVEN**.

## 2) البنية
```
brain/
  server.js            ← Express (أو http خام): مسارات /api/*، تقديم الواجهة، الجلسة
  hr-reader.js         ← موجود جاهز (من HR-Platform-source\tools) — قراءة بيانات برنامج الموظفين
  intents.js           ← محرك الأسئلة (قواعد وكلمات مفتاحية) → يرجّع نص الرد + البيانات
  sources/
    hr.js              ← يغلّف hr-reader: cache 60 ثانية + openReadOnly لأسئلة أعمق
    platforms.js       ← صحة المنصات: sevengates.online / sevencargo.online / sevencargo.co / api.sevengates.online/healthz
    servers.js         ← حالة السيرفرات (ping/healthz فقط؛ لا توجد صلاحية على Coolify)
  public/
    index.html         ← المشهد ثلاثي الأبعاد + لوحة البيانات + الشات
    app.js             ← three.js + التفاعل + الشات + الصوت
    style.css
```
متغيرات البيئة (Coolify): `CC_PASSWORD`, `HR_SYNC_URL`, `HR_SYNC_TOKEN`, `HR_VIEWER_USER`, `HR_VIEWER_PASS`, `PORT`.

## 3) مصادر البيانات (Triggers)
| العنصر في المشهد | المصدر | ما يظهر عند الضغط |
|---|---|---|
| **برنامج الموظفين (HR-Platform)** | `hr-reader.readToday()` + `openReadOnly()` | الموظفون، الحاضرون، المتأخرون، الغائبون، الإجازات، من قبض ومن لم يقبض، السلف المعلّقة، أرصدة الخزينة (رئيسية/فرعية/بنوك)، مستندات تنتهي خلال 30 يوماً، شيكات مستحقة، رقم النسخة ووقت آخر مزامنة |
| **سيرفر المزامنة hr-sync** | `GET https://api.sevengates.online/healthz` | الإصدار، الترخيص مفعّل؟، البريد مفعّل؟، زمن الاستجابة |
| **منصة SEVENGATES** | `GET https://sevengates.online/` (HEAD/GET + زمن) | شغّالة/واقفة، زمن الاستجابة، آخر فحص |
| **منصة SEVENCARGO** | `GET https://sevencargo.online/` | نفس الشيء |
| **موقع الشحن الدولي** | `GET https://sevencargo.co/` | نفس الشيء |
| **سيرفر Hostinger (VPS 1)** | استنتاج من المنصات الثلاث + hr-sync | أخضر لو الكل شغّال، أصفر لو واحد واقع، أحمر لو الكل واقع |
| **سيرفر Hostinger (VPS 2 — sevencargo.co)** | من فحص sevencargo.co | نفس المنطق |
| **المخ نفسه** | process.uptime, memory | مدة التشغيل، الذاكرة، آخر تحديث للبيانات |

كل الفحوص كل 60 ثانية في الخلفية ومخزّنة في الذاكرة؛ الضغط يعرض آخر نتيجة فوراً.

## 4) مسارات الـ API (داخل المخ، خلف الجلسة)
- `POST /login` `{password}` → كوكي جلسة (HttpOnly) 12 ساعة.
- `GET /api/overview` → حالة كل العناصر دفعة واحدة (للمشهد): `{hr:{...}, platforms:[...], servers:[...], brain:{...}, ts}`.
- `GET /api/hr/today` → ناتج `readToday()` كاملاً.
- `GET /api/hr/expiring?days=30` → مستندات تنتهي (`documents` حيث `expiry_date` خلال المدة) مع اسم الموظف ونوع المستند.
- `GET /api/hr/cheques` → شيكات مفتوحة (`cheques` status in held/deposited/deferred) مرتبة بموعد الصرف.
- `GET /api/hr/employee?name=` → بطاقة موظف: الوظيفة، الحالة اليوم، آخر راتب، سلف قائمة، مستنداته وتواريخها (بدون راتب/آيبان/هاتف إلا للمالك المسجَّل دخوله — وهو الوحيد هنا).
- `POST /api/ask` `{text}` → `{answer, speak, data, intent}` (محرك الأسئلة).
- `GET /api/platforms` → نتائج الفحص.

## 5) محرك الأسئلة `intents.js` (مجاني، بالكلمات المفتاحية)
التطبيع: إزالة التشكيل، توحيد (أ/إ/آ→ا، ة→ه، ى→ي)، إزالة "ال" الزائدة، أرقام عربية→إنجليزية. ثم مطابقة أول نيّة تنطبق:

| النيّة | كلمات التفعيل (أمثلة) | الرد |
|---|---|---|
| absent | غايب، غائب، مجاش، محضرش | "الغايبين النهارده N: أسماء" |
| late | متأخر، اتأخر | "المتأخرين N: اسم (وقت الحضور)" |
| present | حاضر، موجود، جه مين | "الحاضرين N من M" |
| onLeave | إجازة، اجازه، مرضي | "في إجازة N: أسماء" |
| unpaid | مقبضش، لم يقبض، لسه ماخدش، المرتبات | "لسه مقبضوش N: أسماء — وقبض N بإجمالي X د.إ" |
| paid | قبض، اتدفع، مرتب مين اتدفع | "قبضوا N: أسماء" |
| payrollDays | الرواتب امتى، يوم القبض، باقي كام يوم | "باقي N يوم على الرواتب" |
| advances | سلفة، سلف، عهدة، عهد، معلق | "طلبات معلّقة N: اسم - نوع - مبلغ" |
| treasury | الخزينة، الخزنة، الفلوس، الرصيد، البنك | "الرئيسية X، الفرعية Y، البنك Z" |
| expiring | إقامة، جواز، تنتهي، منتهي، هتخلص | "مستندات تنتهي خلال 30 يوم N: اسم - نوع - بعد كام يوم" |
| cheques | شيك، شيكات، مستحق | "شيكات مفتوحة N: الطرف - المبلغ - الموعد" |
| employee | اسم موظف موجود في القائمة | بطاقة الموظف |
| platforms | المنصات، المواقع، سيفن جيتس، سيفن كارجو، شغّال، واقع | حالة كل منصة |
| servers | السيرفر، السيرفرات، هوستنجر | حالة السيرفرات |
| summary | ملخص، النهارده، إيه الأخبار، عام | ملخص شامل (كل الأرقام في 3 جمل) |
| help | مساعدة، تقدر تعمل إيه، الأوامر | قائمة الأسئلة المدعومة |
| fallback | أي شيء آخر | "مش فاهم، جرّب: مين غايب؟ / مين مقبضش؟ / الخزينة فيها كام؟ …" |

كل رد يرجع نصاً للعرض ونصاً للنطق (`speak` أقصر) + `data` تُعرض في اللوحة الجانبية (جدول/بطاقات) + `focus` (اسم العنصر ثلاثي الأبعاد الذي يُبرَز، مثلاً `hr` أو `sevengates`).

## 6) الواجهة (public/)
### المشهد ثلاثي الأبعاد (three.js من CDN، بدون ملفات نماذج خارجية — أشكال هندسية مبنية بالكود)
- أرضية شبكية داكنة بألوان SEVENGATES (خلفية `#08141A`، teal `#12B5A6`، gold `#F2A93C`، navy `#0C2138`).
- **سيرفران** (صناديق رف Rack مع أضواء LED تنبض): VPS-1 (Hostinger) وVPS-2.
- **ثلاث منصات** (ألواح/شاشات قائمة بشعار نصي): SEVENGATES، SEVENCARGO، SEVENCARGO.CO.
- **برنامج الموظفين** (مكعب/جهاز كمبيوتر مكتبي بشاشة) موصول بخط متوهّج إلى سيرفر hr-sync (أسطوانة صغيرة على VPS-1).
- **المخ** (كرة متوهّجة في المنتصف) تخرج منها خطوط لكل العناصر.
- لون كل عنصر = حالته (أخضر شغّال، أصفر تحذير، أحمر واقع، رمادي غير معروف). تدوير المشهد بالماوس (OrbitControls)، hover يُظهر الاسم، **click** = Trigger يفتح لوحة البيانات على اليمين ويُبرز العنصر (توهّج + تكبير بسيط) وينطق جملة قصيرة ("برنامج الموظفين: 24 موظف، 3 غايبين، الخزينة 48 ألف").
- تحديث الألوان من `/api/overview` كل 60 ثانية.

### لوحة البيانات (يمين)
- عنوان العنصر + شارات الحالة + جدول/بطاقات حسب العنصر (من الجدول في القسم 3) + زر "تحديث" + وقت آخر تحديث.

### الشات (أسفل)
- حقل نص + زر إرسال + زر 🎤. الكتابة بالإيد أساسية؛ الميكروفون إضافة.
- 🎤: `webkitSpeechRecognition` بلغة `ar-EG` (وتبديل `ar-SA` لو فشل)، النتيجة تُكتب في الحقل وتُرسل تلقائياً.
- الرد يظهر كفقاعة + يُنطق بـ `speechSynthesis` بصوت عربي إن وُجد (زر كتم). لو المتصفح لا يدعم الصوت تظهر رسالة لطيفة وتفضل الكتابة شغّالة.
- أزرار سريعة فوق الحقل: «مين غايب؟» «مين مقبضش؟» «الخزينة» «المستندات» «المنصات» «ملخص».
- يعمل على الموبايل (عرض 400px): المشهد فوق، اللوحة تحت، الشات ثابت أسفل.

## 7) الأمان
- كلمة مرور الدخول من `CC_PASSWORD`؛ 5 محاولات خاطئة = قفل 10 دقائق لكل IP.
- كل مسارات `/api/*` تتطلب الجلسة. لا CORS مفتوح.
- بيانات HR تُقرأ في الذاكرة فقط (hr-reader) ولا تُحفظ على القرص؛ cache 60 ثانية.
- لا يُعرض الراتب/الآيبان/الهاتف في الشات أو اللوحة إلا في بطاقة الموظف للمالك.
- سجل بسيط في الذاكرة لآخر 200 سؤال (للمالك) بدون تخزين دائم.

## 8) خطوات التسليم
1. إضافة `hr-reader.js` و`npm i sql.js express cookie-parser`.
2. ضبط المتغيرات في Coolify وإعادة النشر.
3. اختبار: `/login` → `/api/overview` → `/api/ask` بـ "مين غايب" و"الخزينة فيها كام" و"المنصات شغّالة؟".
4. اختبار الواجهة على Chrome (كمبيوتر وموبايل): الضغط على كل عنصر، الكتابة، الميكروفون، النطق.
5. تسليم الرابط للمالك + ملاحظة بالأسئلة المدعومة.

## 9) ما لا يُنفَّذ الآن (مؤجّل باختيار المالك)
- ذكاء اصطناعي للأسئلة الحرة (يحتاج مفتاح API مدفوع).
- تنبيهات واتساب/بريد (تحتاج خدمة خارجية).
- التحكم في السيرفرات من المركز (إعادة تشغيل/نشر) — خارج نطاق "قراءة فقط".

## ملحق: الأعمدة الفعلية في قاعدة برنامج الموظفين (مؤكدة من main.js — لا تخمين)
- `employees(id, code, name, name_en, job, dept, nationality, phone, email, hire_date, end_date, status['active'|...], currency, basic, allowances, deductions, pay_day, bank, iban, annual_leave, birth_date, gender, notes)`
- `documents(id, emp_id, type, number, issue_date, expiry_date, file_id, file_name, note)` — التواريخ نص `YYYY-MM-DD`. "تنتهي خلال 30 يوم" = `expiry_date BETWEEN today AND today+30`.
- `cheques(id, kind['in'|'out'], number, bank, party, amount, currency, issue_date, due_date, due_note, status, account, note, emp_id, treasury_id, cleared_at, vno, project_id)` — الشيكات المفتوحة: `status IN ('held','deposited','deferred')`؛ المغلقة: `cleared`/`bounced`/`cancelled`. ترتيب الاستحقاق بـ `due_date`.
- `attendance(id, emp_id, date, status, site, task, client, check_in, check_out, note)`
- `leaves(id, emp_id, type, start_date, end_date, days, note)`
- `payments(id, emp_id, month['YYYY-MM'], basic, allowances, bonus, deductions, amount, currency, paid_at, note)`
- `advances(id, emp_id, kind, amount, currency, reason, request_date, status, approved_by, approved_at, installments, installment_amount, disbursed_at, remaining, note)` — المعلّقة: `status='pending'`.
- `expenses(id, date, emp_id, category, amount, currency, description, custody_id, status, approved_by, paid_from, ...)`
- `projects(id, vno, name, client, status, start_date, end_date, budget, notes)`
- `assets(id, emp_id, kind, name, serial, qty, value, received_date, condition, notes, status['with'|...], returned_date)` — العُهد العينية.
- الحذف المنطقي: جدول `tombstones(tbl,id)` — استبعد أي صف id موجود فيه لنفس الجدول.
